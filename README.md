# SpaceGame
A repo containing a tactical turn-based space combat game inspired by FTL. You command a starship and must defeat enemy vessels by managing your crew's morale, upgrading your systems, and learning about your opponent through combat.

About the Project

SpaceGame is developed as a learning-focused project. The goal is to keep the code modular, well-documented, and easy to extend so it can serve both as a playable prototype and as example code for game architecture patterns.

🎮 About the Game

- Control a starship and its crew
- Manage resources, ship systems, and crew morale
- Upgrade systems between encounters
- Compete against enemy ships in tactical turn-based combat

This version aims to preserve simple, engaging mechanics while keeping the codebase maintainable and testable.

🛠 Tech Stack

- Python 3.12+
- Pygame
- Poetry (dependency management)
- Git & GitHub for version control

💡 Commit Structure

- 🚀 feat: New feature added to the project
- 🐛 fix: Bugfix
- ♻ refactor: Code improvements without changing functionality
- 📚 docs: Documentation changes
